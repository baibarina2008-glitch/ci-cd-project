
# Документация CI/CD

## Что такое CI/CD?
CI/CD — это процесс автоматической сборки, проверки и подготовки проекта.

## Схема работы

1. **Push** — отправка изменений в GitHub.
2. **Workflow** — автоматический запуск процесса GitHub Actions.
3. **Контейнер** — среда, в которой выполняется проверка.
4. **Проверка** — тестирование проекта на ошибки.
5. **Результат** — успешное выполнение или сообщение об ошибке.

## Схема процесса

Push → Workflow → Контейнер → Проверка → Результат

## Вывод
CI/CD помогает автоматически проверять проект и находить ошибки.
